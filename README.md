# Fork/REBS Confluence — public evidence
Prepared public scaffold for selected, reviewed reproducible artifacts.

No research release is included in this initial scaffold. Publication, successful tests, and scientific admission are distinct dispositions. Each future release must identify scope, source/version references permitted for disclosure, hashes, reproduction instructions, failures, limitations and its explicit disposition.

Research preparation occurs separately. Private repository history is not mirrored here. No license grant or endorsement is implied by this scaffold.
